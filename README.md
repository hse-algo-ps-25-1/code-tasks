# Задание №0 👋

Это **демонстрационное** задание: пройти процесс выпонения задания по программированию и познакомиться с Git/GitHub. Задание не оценивается.

## До выполнения

Рабочее место — по инструкции [Установка необходимого ПО](https://github.com/hse-algo-ps-25-1/docs/blob/main/%D0%A3%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0%20%D0%BD%D0%B5%D0%BE%D0%B1%D1%85%D0%BE%D0%B4%D0%B8%D0%BC%D0%BE%D0%B3%D0%BE%20%D0%9F%D0%9E.md):

1. Зарегистрироваться на GitHub и отправить преподавателю логин — вас добавят в организацию.
2. Принять приглашение в организацию (нужно, чтобы пушить и открывать pull request).
3. Установить **Python 3.14**, Git и VS Code с расширениями из инструкции.
4. Клонировать этот репозиторий (`code-tasks`).
5. Создать виртуальное окружение `.venv` и выполнить `pip install -r requirements.txt` в терминале с префиксом `(.venv)`.

Подробный сценарий сдачи (скриншоты, flake8, PR) — в [Выполнение задания по программированию](https://github.com/hse-algo-ps-25-1/docs/blob/main/%D0%92%D1%8B%D0%BF%D0%BE%D0%BB%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5%20%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D1%8F%20%D0%BF%D0%BE%20%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8E.md).

## Для выполнения задания

Команды ниже — в терминале с префиксом `(.venv)`. В `main` не коммитить.

1. Получить ветки с сервера и переключиться на задание: `git fetch origin`, затем `git checkout main-task-0`.
2. От `main-task-0` **создать свою ветку**, подставив название учебной команды вместо `team-name`: `git checkout -b team-name-task-0`.
3. В файле `main.py` реализовать функцию `hello`.
4. Запустить модульный тест — файл `test.py`.
5. Сортировка импортов: `python -m isort .`
6. Форматирование: `python -m black .`
7. Проверка синтаксиса и стиля: `python -m flake8 . --max-complexity=10 --max-line-length=88 --exclude .venv`  
   Команда должна завершиться без ошибок. Зелёные Checks на GitHub стиль **не** подтверждают — см. инструкцию по выполнению.
8. Зафиксировать изменения (`git commit`).
9. Отправить ветку в репозиторий на GitHub (`git push`).
10. Создать pull request: **base** — `main-task-0`, **compare** — `team-name-task-0`. В заголовке — имя вашей ветки или задание и команда. После ревью запрос **закроют без слияния** с `main-task-0`.
